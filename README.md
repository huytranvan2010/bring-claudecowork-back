## About

Claude Chat and Claude Cowork were recently merged into a single interface. We hope Anthropic will bring Claude Cowork back as before, as a dedicated experience separate from Claude Chat.

This page lets the community show support with one click, and explains how to send feedback through Anthropic's official channels (the feedback buttons in the Claude app, or [support.claude.com](https://support.claude.com)).

<a id="why"></a>

## Why a separate Cowork

1. **Dedicated global instructions**, not mixed with Chat.
2. **Transparent progress and tool use**, so users can step in early.
3. **File management in the workspace**: inputs, intermediates, and deliverables stay visible.
4. **A `CLAUDE.md` per folder**, so context follows the project.
5. **Task specialization** for the best output.
6. **Clear access boundaries**, safer by design.

Full wording is on the website.
