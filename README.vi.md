## Giới thiệu

Trang này giúp cộng đồng bày tỏ sự ủng hộ chỉ với một cú bấm, đồng thời hướng dẫn gửi phản hồi qua các kênh chính thức của Anthropic (nút phản hồi trong ứng dụng Claude, hoặc [support.claude.com](https://support.claude.com)).

## Vì sao nên tách riêng Cowork

2. **Theo dõi tiến độ và công cụ được dùng một cách minh bạch**, để can thiệp sớm.
3. **Quản lý file ngay trên giao diện làm việc**: file đầu vào, file trung gian và thành phẩm luôn hiển thị.
4. **`CLAUDE.md` riêng cho từng folder**, ngữ cảnh đi theo dự án.
5. **Chuyên biệt hóa tác vụ** để có đầu ra tốt nhất.
